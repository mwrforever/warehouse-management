# 商品库存管理系统（含完整生产业务）设计文档

- 日期：2026-08-12
- 状态：已获用户确认（架构/流程/前端设计三节全部通过）

## 1. 项目目标

为公司构建一套**进销存 + 完整生产业务**的一体化库存管理系统，覆盖：采购入库、销售出库、库存管理（余额/流水/盘点/预警）、生产管理（工单/BOM/领料/工序流转/委外/报工/成品入库）、统计报表与仪表盘。

## 2. 技术选型（已调研）

| 层 | 选型 | 依据 |
|---|---|---|
| 后端框架 | **Laravel 13**（PHP 8.5.9 本机已装） | 调研结论：Laravel 13 发布于 2026-03-17，官方支持 PHP 8.3–8.5，安全修复至 2027-09；Laravel 12 缺陷修复将于 2026-08-13 到期（已近 EOL）；ThinkPHP 8.1 兼容 PHP 8.5 但工程化（迁移/测试/队列）弱于 Laravel |
| 数据库 | **MySQL 8.4 LTS**（Docker 29.6.2 本机已有） | PHP 已启用 pdo_mysql；docker-compose 管理，数据卷挂载项目内 |
| 前端 | **Vue 3 + TypeScript + Vite + Pinia + Vue Router + Element Plus** | 进销存/生产单据类复杂表格表单场景 Element Plus 生态最成熟；样式经设计系统深度定制 |
| 认证 | Laravel Sanctum（Bearer Token） | 前后端分离标准方案 |
| 测试 | 后端 PHPUnit；前端 Vitest | 见 §8 |

## 3. 需求边界（用户已确认）

1. **生产业务为完整版**：生产工单 + BOM + 领料/退料 + 多工序流转与报工 + 委外加工 + 成品入库 + 生产统计
2. **模块范围**：库存 + 生产 + 采购 + 销售全闭环
3. **支持扫码枪**：所有出入库/领料/盘点/工序交接单据支持扫码输入
4. **单据流程**：制单 → 审核两级状态，审核后库存才变动

## 5. 模块清单（8 大模块）

1. **系统管理**：用户、角色（RBAC）、权限、字典
2. **基础资料**：商品（原料/半成品/成品）、分类、计量单位、仓库/库位、供应商、客户、BOM（单头+明细）、工序
3. **采购管理**：采购订单 → 采购入库单
4. **销售管理**：销售订单 → 销售出库单
5. **库存管理**：库存余额、出入库流水、库存盘点、库存预警（上下限）
6. **生产管理**：生产工单、领料单、退料单、工单工序、工序报工、委外加工单、委外回收、成品入库
7. **统计报表**：库存报表、出入库汇总、生产统计（工单达成率/良率/工时/物料耗用）、采购销售汇总
8. **仪表盘**：库存总值、今日出入库、待审核单据、工单进度、库存预警列表

## 6. 数据模型（核心表 ~32 张）

```
基础资料: products(类型: 原料/半成品/成品) categories units warehouses locations
          suppliers customers processes bom_headers bom_items
采购/销售: purchase_orders(+items) purchase_inbounds(+items)
          sales_orders(+items) sales_outbounds(+items)
库存:     inventory_balances(余额,含上下限) inventory_movements(流水·一切变动源头)
          inventory_checks(+items)
生产:     production_orders(工单) pick_lists(领料) return_lists(退料)
          work_order_operations(工单工序) operation_reports(报工)
          outsourcing_orders(委外) outsourcing_receipts(委外回收)
系统:     users roles permissions role_user permission_role dictionaries
```

**核心不变式**：所有库存变动（采购入库/销售出库/领料/退料/成品入库/委外收发/盘点）统一写 `inventory_movements` 流水并更新 `inventory_balances`，全部在数据库事务内完成；余额计算以流水为唯一事实来源，禁止旁路修改。

## 7. 业务流程与状态机

### 7.1 单据状态机（审核后库存才变动）

| 单据 | 状态流转 |
|---|---|
| 采购订单 | 草稿 → 已审核 → 部分入库 → 已完成 → 关闭 |
| 采购入库单 | 草稿 → 已审核（库存+） |
| 销售订单 | 草稿 → 已审核 → 部分出库 → 已完成 → 关闭 |
| 销售出库单 | 草稿 → 已审核（库存-） |
| 领料单 | 草稿 → 已审核（原料-）→ 部分/全部发料 |
| 退料单 | 草稿 → 已审核（原料+，冲销领料） |
| 生产工单 | 草稿 → 已下达 → 生产中 → 已完成 → 关闭 |
| 委外单 | 草稿 → 已审核（发出）→ 已回收 |
| 成品入库单 | 草稿 → 已审核（成品+，联动工单完工） |
| 盘点单 | 草稿 → 已审核（盘盈/盘亏生成流水） |

### 7.2 生产业务主链路

```
生产工单(产品+数量+计划日期)
   ├─ BOM 展开 → 物料需求 → 领料单(仓库发料)
   ├─ 工序流转: 工序1 → 工序2 → …（每工序独立报工: 合格/不良/工时）
   │     ├─ 工序状态: 待开工 → 进行中 → 已完成
   │     ├─ 委外: 委外单(发出) → 回收(入库)
   │     └─ 不良: 报工时记录不良数（V1 仅记录与统计，返修/报废处置流程预留后续版本扩展）
   ├─ 报工汇总 → 工单完工数量 → 成品入库单(合格品入成品库)
   └─ 工单关闭 → 生产统计(达成率/良率/工时/物料耗用)
```

### 7.3 库存预警

商品维护安全库存上下限；库存低于下限或高于上限时，仪表盘与库存列表显示红/黄状态标记。

## 8. API 约定

- RESTful：`/api/v1/*`，资源化路由
- 认证：Sanctum Token（登录 → Bearer Token）
- 权限：RBAC 中间件 `permission:xxx`，前端路由守卫同步
- 统一响应：`{code, message, data}`；分页 `{items, total, page, per_page}`
- 单号规则：模块前缀 + 日期 + 流水（如 `PO20260812-001`、`MO20260812-001`）
- 所有写操作在事务内执行，失败整体回滚
